How

Route, scope, ship, verify.

Four steps. No ceremony.

1. Route

Classify S/M/L/XL via 6-signal scoring. Start narrow. Escalate on contradiction.

2. Scope contract

Restate objective, list touched files, note blast radius, define validation.

3. Ship smallest

Reuse existing, stdlib, deps. Delete > add. Finish all callers and tests.

4. Verify

Cheapest check that catches likely regression. Report change + verification + risk.
