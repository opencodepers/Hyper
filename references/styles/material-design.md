# Material Design

## Summary
Google's paper metaphor with elevation via shadows, ripple feedback, grid, bold color.

## Traits
- Paper metaphor
- Elevation via shadows
- Ripple feedback on touch
- 8dp grid system
- Bold primary color
- Roboto typography

## CSS
```css
box-shadow: 0 2px 4px rgba(0,0,0,.2);
border-radius: 4px;
```

## When to use
Android apps, enterprise, structured products

## When to avoid
Overuse of elevation; generic look
