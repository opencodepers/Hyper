# Glassmorphism

## Summary
Frosted glass surfaces with blur, transparency, thin light borders.

## Traits
- backdrop-filter blur
- Semi-transparent white surface
- Thin light border
- Soft shadow for depth
- Works over colorful backgrounds

## CSS
```css
backdrop-filter: blur(18px) saturate(160%);
background: rgba(255,255,255,.15);
border: 1px solid rgba(255,255,255,.25);
```

## When to use
Overlays, modals, hero sections

## When to avoid
Overuse on static cards (low contrast, slow)
