# Skeuomorphism

## Summary
A style that mimics real-world physical objects through textures, shadows, and gradients.

## Traits
- Real-world textures (leather, wood, metal)
- Glossy buttons with highlights
- Drop shadows for depth
- Gradients mimicking light
- High fidelity, tactile feel
- Rounded corners like physical objects

## CSS
```css
background: linear-gradient(#eee,#ccc);
box-shadow: 0 2px 4px rgba(0,0,0,.3);
border-radius: 8px;
```

## When to use
Games, nostalgic apps, tactile products

## When to avoid
Modern minimal products; dated look
