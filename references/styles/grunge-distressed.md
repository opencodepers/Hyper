# Grunge / distressed

## Summary
Rough textures, torn edges, dark, chaotic.

## Traits
- Rough textures
- Torn edges
- Dark palette
- Chaotic layout
- Raw feel

## CSS
```css
filter: contrast(1.2);
background: url(texture.png);
```

## When to use
Music, alternative, edgy

## When to avoid
Corporate, clean products
