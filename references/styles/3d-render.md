# 3D render illustration

## Summary
3D rendered objects with soft lighting, pastel backgrounds, depth.

## Traits
- 3D rendered objects
- Soft lighting
- Pastel backgrounds
- Depth and parallax
- Illustrative

## CSS
```css
/* use 3D model/image */
transform: perspective(1000px) rotateY(10deg);
```

## When to use
Hero illustrations, marketing

## When to avoid
