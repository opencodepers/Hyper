# Neo-brutalism

## Summary
Bold, raw aesthetic with thick borders, hard offset shadows, saturated colors.

## Traits
- Thick borders (3-5px solid)
- Hard offset shadow, zero blur (4px 4px 0)
- High contrast saturated colors
- Bold geometric sans
- Sharp corners (0-4px)
- Exposed box model

## CSS
```css
border: 3px solid #0A0A0A;
box-shadow: 4px 4px 0 #0A0A0A;
border-radius: 4px;
```

## When to use
Bold brands, startups, expressive products

## When to avoid
Soft shadows, excessive rounding, gradients
