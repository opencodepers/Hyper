# Enterprise / B2B

## Summary
Dense, 28-36px rows, 4px radii, hairline dividers, muted palette, data-first.

## Traits
- Dense layout
- Small type (13px)
- 4px radii
- Hairline dividers
- Muted palette
- Data-first

## CSS
```css
font-size: 13px;
border: 1px solid #e5e5e5;
border-radius: 4px;
```

## When to use
B2B, dashboards, enterprise

## When to avoid
Consumer/marketing
