# Liquid glass

## Summary
Fluid, organic glass surfaces with heavy blur and flowing shapes (Apple-style).

## Traits
- Heavy blur (40px+)
- Organic flowing shapes
- High saturation
- Rounded/pill shapes
- Translucent surfaces

## CSS
```css
backdrop-filter: blur(40px) saturate(180%);
border-radius: 999px;
```

## When to use
Apple-style, premium, fluid UI

## When to avoid
Performance on low-end devices
