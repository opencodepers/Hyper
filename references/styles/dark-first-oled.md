# Dark-first / OLED

## Summary
True black (#000), elevation via border, desaturated hues, OLED-friendly.

## Traits
- True black background
- Elevation via border
- Desaturated accents
- OLED-friendly
- High contrast

## CSS
```css
background: #000;
color: #e5e5e5;
border: 1px solid #222;
```

## When to use
Dark mode apps, OLED devices

## When to avoid
Print, light contexts
