# Aurora / mesh gradients

## Summary
Blurred multi-color gradient blobs behind content, subtly animated.

## Traits
- Blurred gradient blobs
- Multi-color, high saturation
- Animated subtly
- Dark or light base
- Depth and atmosphere

## CSS
```css
background: radial-gradient(...);
filter: blur(60px);
```

## When to use
Hero sections, landing pages

## When to avoid
Overuse; performance/CLS issues
