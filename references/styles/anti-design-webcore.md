# Anti-design / webcore

## Summary
Deliberately chaotic, broken layouts, clashing colors, raw.

## Traits
- Chaotic layouts
- Clashing colors
- Broken grids
- Raw, unpolished
- Provocative

## CSS
```css
transform: rotate(3deg);
color: #ff00ff;
background: #00ff00;
```

## When to use
Art, experimental, statement

## When to avoid
Usability-critical products
