# Luxury / premium

## Summary
Generous whitespace, thin weights, serif display, muted palette, slow subtle motion.

## Traits
- Generous whitespace
- Thin font weights
- Serif display
- Muted palette (black, cream, gold)
- High-quality imagery
- Slow subtle motion

## CSS
```css
font-family: 'Cormorant', serif;
color: #1a1a1a;
letter-spacing: .05em;
```

## When to use
Fashion, luxury, high-end brands

## When to avoid
Fast-paced, dense apps
