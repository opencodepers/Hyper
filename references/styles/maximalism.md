# Maximalism

## Summary
Dense, layered, bold colors, mixed patterns — more is more.

## Traits
- Dense layouts
- Layered elements
- Bold colors
- Mixed patterns
- High energy

## CSS
```css
background: #000;
color: #ff0;
font-weight: 900;
```

## When to use
Expressive brands, editorial

## When to avoid
Data-heavy apps
