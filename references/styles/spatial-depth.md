# Spatial / depth

## Summary
Z-depth, layered planes, parallax, 3D transforms.

## Traits
- Z-depth layering
- Parallax scrolling
- 3D transforms
- Spatial navigation
- Immersive

## CSS
```css
transform: translateZ(20px);
perspective: 1000px;
```

## When to use
Immersive experiences, gaming

## When to avoid
Simple content sites
