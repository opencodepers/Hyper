# Fluent Design

## Summary
Microsoft's light, depth, motion, material (acrylic), reveal highlight, layered system.

## Traits
- Light and depth
- Acrylic material
- Reveal highlight on hover
- Layered surfaces
- Motion and parallax
- Adaptive to platform

## CSS
```css
backdrop-filter: blur(30px);
background: rgba(255,255,255,.7);
```

## When to use
Windows apps, enterprise

## When to avoid
Non-Microsoft platforms (feels foreign)
