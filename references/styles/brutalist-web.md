# Brutalist web

## Summary
Raw, unstyled-feeling HTML with system fonts, high contrast, exposed structure.

## Traits
- Raw, unstyled-feeling HTML
- System fonts, default underlines
- High contrast black/white
- Asymmetric layouts
- Exposed structure, no decoration
- Intentionally 'ugly' but functional

## CSS
```css
font-family: system-ui;
text-decoration: underline;
```

## When to use
Artistic, experimental, statement sites

## When to avoid
Mainstream consumer products
