# Isometric / axonometric

## Summary
3D isometric illustrations, grid-aligned, technical.

## Traits
- Isometric illustrations
- Grid-aligned
- 3D transforms
- Technical feel
- Diagrammatic

## CSS
```css
transform: rotateX(60deg) rotateZ(-45deg);
```

## When to use
Tech, SaaS, explanatory

## When to avoid
Organic brands
