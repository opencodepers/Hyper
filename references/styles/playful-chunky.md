# Playful chunky

## Summary
Rounded, thick, friendly, bright, toy-like.

## Traits
- Rounded shapes
- Thick strokes
- Friendly, bright colors
- Toy-like feel
- Bold type

## CSS
```css
border-radius: 24px;
font-weight: 800;
background: #ffcc00;
```

## When to use
Kids, playful products

## When to avoid
Serious/enterprise
