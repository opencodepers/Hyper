# Flat design

## Summary
A 2D style with no shadows or gradients, solid colors, simple icons, clean typography.

## Traits
- No shadows or gradients
- Solid flat colors
- Simple vector icons
- Clean sans-serif typography
- Minimal decoration
- 2D surfaces

## CSS
```css
background: #fff;
color: #111;
border: none;
box-shadow: none;
```

## When to use
Universal, mobile apps, modern products

## When to avoid
When affordance cues needed
