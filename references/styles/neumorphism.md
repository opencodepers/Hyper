# Neumorphism

## Summary
Soft UI where background matches surface; dual shadows create extrusion/intrusion.

## Traits
- Background matches surface color
- Dual shadows (light+dark)
- Soft, low-contrast
- Extruded/intruded elements
- Rounded corners

## CSS
```css
box-shadow: 8px 8px 16px #d1d9e6, -8px -8px 16px #f0f8ff;
border-radius: 12px;
```

## When to use
Decorative, tactile surfaces

## When to avoid
Text contrast; accessibility risk
