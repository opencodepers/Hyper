# Claymorphism

## Summary
Soft, puffy 3D with inner+outer shadows, rounded corners, pastel colors.

## Traits
- Puffy 3D look
- Inner + outer shadows
- Rounded corners (20-30px)
- Pastel colors
- Soft, friendly feel

## CSS
```css
border-radius: 24px;
box-shadow: inset 0 -4px 8px rgba(0,0,0,.1), 0 8px 16px rgba(0,0,0,.1);
```

## When to use
Playful, friendly products

## When to avoid
Serious/enterprise contexts
