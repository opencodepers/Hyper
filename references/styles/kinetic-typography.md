# Kinetic typography

## Summary
Animated text as hero, large type, motion-driven.

## Traits
- Animated text
- Large type as hero
- Motion-driven
- Bold weights
- Dynamic layout

## CSS
```css
animation: slide 1s;
font-size: 120px;
font-weight: 900;
```

## When to use
Hero sections, storytelling

## When to avoid
Dense data
