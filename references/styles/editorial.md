# Editorial

## Summary
Magazine-like layouts with large serif display, narrow reading column, drop caps.

## Traits
- Large serif display type
- Narrow reading column (60-75ch)
- Drop caps, pull quotes
- Wide margins
- Serif display + humanist body
- OpenType features

## CSS
```css
font-family: 'Fraunces', serif;
max-width: 65ch;
```

## When to use
Long-form content, magazines, blogs

## When to avoid
Dense app UIs
