# Japanese web density

## Summary
Dense, information-rich, small type, many links, compact.

## Traits
- Dense layout
- Small type (12px)
- Many links
- Compact spacing
- Information-rich

## CSS
```css
font-size: 12px;
line-height: 1.4;
padding: 4px;
```

## When to use
Japanese sites, info-heavy

## When to avoid
Western minimal aesthetic
