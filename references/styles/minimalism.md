# Minimalism

## Summary
Maximum whitespace, minimal elements, monochrome or one accent, content-first.

## Traits
- Maximum whitespace
- Minimal elements
- Monochrome or one accent
- Clean sans-serif
- Hairline borders, no shadows
- Content-first; remove until it breaks

## CSS
```css
padding: 48px;
color: #111;
border: 1px solid #eee;
```

## When to use
Premium, focused, content-heavy

## When to avoid
Complex data-heavy apps
