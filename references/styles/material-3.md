# Material 3 (Material You)

## Summary
Dynamic color from wallpaper, tonal palettes, rounded corners, personalization.

## Traits
- Dynamic color from user wallpaper
- Tonal color palettes
- Rounded corners (28px)
- Personalized themes
- Motion and state layers

## CSS
```css
border-radius: 28px;
background: var(--md-sys-color-primary-container);
```

## When to use
Android 12+, personalized apps

## When to avoid
Fixed brand color requirements
