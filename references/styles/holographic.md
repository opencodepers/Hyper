# Holographic / iridescent

## Summary
Rainbow shimmer, shifting colors, metallic sheen.

## Traits
- Rainbow shimmer
- Shifting colors
- Metallic sheen
- Blur and glow
- Futuristic feel

## CSS
```css
background: linear-gradient(135deg,#ff0080,#7928ca,#ff0080);
background-size: 200% 200%;
animation: shift 4s;
```

## When to use
Premium, futuristic, accent

## When to avoid
Overuse; readability
