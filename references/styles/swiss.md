# Swiss (International)

## Summary
Grid-based, asymmetric layouts with strong typography hierarchy and generous whitespace.

## Traits
- Grid-based asymmetric layouts
- Helvetica/neo-grotesque type
- Strong type hierarchy
- Generous whitespace
- Limited palette (often red accent)
- Objective, clean, functional

## CSS
```css
font-family: Helvetica, Arial, sans-serif;
display: grid;
gap: 24px;
```

## When to use
Editorial, corporate, structured content

## When to avoid
Playful or organic products
